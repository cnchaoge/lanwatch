# Lanwatch

从这台电脑看出网断在哪一段。

域名：lanwatch.cn · lanwatch.net

## 链路单

窗口里是一张单。六段从上到下：这台电脑、网卡、路由器、DNS、代理、外网。

每段标 **通**、**慢** 或 **断**，旁边一个数，下面一行事实。最上面一句结论，写已看了多久。最下面一件下一步，和「再测一次」。出问题的那一段可以补一句，记在本机。

窗口开着就大约每 6 秒再测一轮。每段旁边留最近十几次的通、慢、断，新的在右边。「再测一次」会马上重测。

结论落在第一处断上。没有断，就落在第一处慢上。外网格子仍是「通」，但这一个网址是证书问题或连不上时，结论改说这件事。

## 每一段

- **这台电脑**：本机名字，回环是否回应。收发明显时写出发出和收到。这台电脑自己在占带宽，同时路由器或外网变慢，就判在这一段。本机地址有两块网卡，也记在这里。
- **网卡**：地址，以及 Wi-Fi 或有线。无线带信号、噪声和实际速率。信号弱、噪声大，或速率掉到 24 Mbps 以下，算慢。地址以 `169.254` 开头，表示路由器没有发地址。
- **路由器**：网关地址、往返时间和丢包。网关地址有两块网卡在应答，或硬件地址在两次测量之间变了，也记在这里。
- **DNS**：正在用的服务器，和解析一次要多久。
- **代理**：系统代理关掉就是直连，数是 0。开着就看它是否在听、能不能把流量送出去，以及比直连慢多少。
- **外网**：通断仍看能不能连上 `223.5.5.5` 或 `1.1.1.1`，旁边的数是这一次 TCP 的时间，不是 ping 的时间。这一段下面另有事实，读的是路径，不是「有没有回应」这一件事：
  - **每一跳**：直连路径上每一跳的时间、丢包和 ASN。某一跳不回、后面又有回应，记成「不回」，不当成线路中断。终点 ping 有丢包才把这一段标成慢。traceroute 没走完、但 443 端口是通的，跳数写「没有读到」，通断仍按端口。
  - **NAT**：本机地址和出口地址。对得上写「没有地址转换」；对不上写 `NAT a → b`。两次映射的公网端口不同，加「对称」。路径上有 `100.64` 开头的地址，记运营商这一层。没读到出口地址就不写。
  - **证书**：默认看 `www.baidu.com`。把打不开的网址写在这一段，回车后再测那一个。连上了但证书不合格，写「证书… · 连得上」，这一段仍是通。地址没有连上，写「连不上」或「没有解析」，不写成证书问题。系统代理开着时，证书按代理那条路看。跳数始终是直连；代理开着时，跳的前面标「直连」。

外网是结论落点时，单子下面有一张步骤：先看什么，以及哪些事不会自动做。不会改 DNS，不会关代理，不会重启光猫，也不会信任证书。

单子上的流量只来自这台电脑自己的网卡。

## 运行

在 macOS 上跑。需要 Node.js、Rust，以及 Xcode 自带的 `swiftc`（用来读无线信号、噪声和速率）。

```sh
npm install
npm start
```

`npm start` 会先编译无线辅助程序，再打开窗口。`swiftc` 不可用时窗口仍能打开，无线信号会缺一块。外网这一段还会用到系统自带的 `traceroute`、`dig` 和 `curl`。缺了哪一个，对应的事实留空，通断仍按原来的端口来。

路径断掉时，每一跳要等回应，一轮可能要十秒左右。窗口上会停在「正在测」。

## 测试

逻辑测试不连外网。编译时要能看见 `src-tauri/resources/wifi-helper`。有 `swiftc` 时先编辅助程序；没有的话放一个空文件即可：

```sh
sh scripts/build-wifi-helper.sh
# 或者：: > src-tauri/resources/wifi-helper
cargo test --manifest-path src-tauri/Cargo.toml
```

在这台 Mac 上连一次真网（会调用 `route`、`ping`、`traceroute`）：

```sh
cargo test --manifest-path src-tauri/Cargo.toml -- --ignored live_on_this_mac
```

证书这句话对不对，可以用真的 curl 再对一次（要能访问外网）：

```sh
cargo test --manifest-path src-tauri/Cargo.toml --lib live_certificate_words_match_curl -- --ignored
```

窗口仍用 `npm install` 然后 `npm start`。把打不开的网址写在外网那一行，回车。证书不合格时，这一段保持「通」，句子里能分开「连得上」和「连不上」。
